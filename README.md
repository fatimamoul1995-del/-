# # حساب الكاس

تطبيق **حساب الكاس** هو أداة تساعدك على حساب الكميات بدقة باستخدام "كأس العنبة". بكل سهولة، يقدر المستخدم يحسب المقادير لأي مكون في المطبخ، سواء كان حليب، سكر، سمسم أو زيت. التطبيق سهل الاستخدام وفعّال، وكيخليك تحضر الوصفات بكل دقة وسرعة.

## المميزات:
- حساب الكمية الدقيقة لأي مكون بناءً على "كأس العنبة".
- واجهة مستخدم بسيطة وسهلة.
- يدعم العديد من المكونات مثل السكر، الحليب، الزيت، السمسم وغيرها.
- سهل الاستخدام ويمكن الوصول إليه مباشرة من المتصفح.

## كيفية التثبيت:
1. **تحميل الكود**:
   - قم بتحميل المشروع عبر Git:
     ```bash
     git clone https://github.com/username/repository-name.git
     ```
2. **تشغيل التطبيق**:
   - افتح الملف `index.html` في المتصفح لعرض التطبيق.

## كيفية الاستخدام:
- اختر المكون (مثل السكر، الحليب، الزيت، إلخ).
- أدخل الكمية المطلوبة بـ "كأس العنبة".
- اضغط على **"احسب"** للحصول على الكمية الدقيقة.
